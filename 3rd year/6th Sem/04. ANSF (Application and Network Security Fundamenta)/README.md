| **Unit**  | **Title**                                   | **Topics** |
|-----------|---------------------------------------------|------------|
| **Unit 1** | **Introduction** | Objective, scope, and outcome of the course. |
| **Unit 2** | **Basic Cyber Security Concepts** | - Concepts of Confidentiality, Integrity, and Availability (CIA) <br> - Threat Modeling <br> - Overview of Security Models (OSI and TCP/IP Models) <br> - Cyber Security Basic Terminologies |
| **Unit 3** | **Security Threats, Vulnerabilities & Attacks** | - Network Protocols <br> - Threat, Vulnerability, and Attack <br> - TCP Handshaking <br> - Password-Based & Address-Based Authentication <br> - Cryptographic Authentication (Passwords as keys, protocols, KDC, Certification Revocation, Inter-domain, groups, delegation) <br> - Authentication of People (Verification techniques, passwords, smart cards, biometrics) |
| **Unit 4** | **Application Security** | - Security for E-commerce (SSL, SET) <br> - System Security (Intrusion Detection, Malicious Software, Firewalls) <br> - Authentication Applications (Kerberos, X.509) <br> - Email Security (PGP, S/MIME) <br> - IP Security (IPSec Architecture, AH, ESP, Key Management) <br> - Kerberos V5 (Realms, Delegation, Ticket Lifetimes, Multiple Realms) |
| **Unit 5** | **Network & Security Devices** | - Network Management Security <br> - Security Hardening Guidelines for Devices <br> - Network Vulnerability Assessment Phases <br> - Device Auditing (Switch, Firewall, Router, Core-Switch) <br> - Web Security (SSL/TLS, Secure Electronic Transaction) |
| **Unit 6** | **Security Policies and Handshake** | - Digital Signatures & Authentication Protocols <br> - Digital Signature Standard (DSS) <br> - Security Policies (High & Low Level, User Issues) <br> - Protocol Problems & Assumptions <br> - Shared Secret & Public Key Protocols <br> - Mutual Authentication |

This table provides a structured overview of the course content. Let me know if you'd like any modifications!
