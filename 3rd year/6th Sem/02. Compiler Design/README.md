| Unit | Title                          | Subtopics                                                                 |
|------|--------------------------------|--------------------------------------------------------------------------|
| 1    | **Introduction**               | - Objective, scope, and outcome of the course<br>- Compiler, Translator, Interpreter definitions<br>- Phases of a compiler<br>- Bootstrapping [Go](https://www.geeksforgeeks.org/compiler-design/bootstrapping-in-compiler-design/)  <br>- Review of Finite automata lexical analyzer [GO](https://www.tutorialspoint.com/compiler_design/compiler_design_finite_automata.htm)<br>- Input and recognition of tokens[GO]()             <br>- LEX: A lexical analyzer generator[GO]()                 <br>- Error handling [GO]() | 6 |
| 2    | **Review of CFG & Parsing**    | - Ambiguity in grammars [GO](https://www.geeksforgeeks.org/compiler-design/ambiguous-grammar/)    <br>- Top-down parsing (LL grammars, recursive descent) [GO](https://www.tutorialspoint.com/compiler_design/compiler_design_top_down_parser.htm)  <br>- Bottom-up parsing (Shift-reduce, LR parsers) [GO](https://www.tutorialspoint.com/compiler_design/compiler_design_bottom_up_parser.htm)   <br>- Construction of SLR, CLR, and LALR parsing tables [GO](https://www.geeksforgeeks.org/compiler-design/slr-clr-and-lalr-parsers-set-3/)     <br>- Parsing with ambiguous grammars [GO](https://www.geeksforgeeks.org/compiler-design/parsing-ambiguos-grammars-using-lr-parser/)    <br>- Operator precedence parsing [GO](https://www.geeksforgeeks.org/compiler-design/role-of-operator-precedence-parser/)  <br>- YACC: Automatic parser generator [GO](https://www.geeksforgeeks.org/compiler-design/introduction-to-yacc/)                     <br>- Error handling in LR parsers[GO](https://www.geeksforgeeks.org/compiler-design/error-recovery-in-lr-parsing/) | 10 |
| 3    | **Syntax-Directed Translation** | - Construction of syntax trees<br>- S-Attributed and L-Attributed definitions<br>- Top-down translation<br>- Intermediate code forms (postfix, DAG, Three-address code)<br>- TAC for control structures<br>- Triples and quadruples representation<br>- Boolean expressions and control structures | 10 |
| 4    | **Runtime Environments**       | - Storage allocation strategies<br>- Heap management<br>- Activation records<br>- Accessing local/non-local names<br>- Parameter passing<br>- Symbol table organization and data structures | 8 |
| 5    | **Optimization & Code Generation** | - Basic blocks and control flow graphs<br>- DAG representation and advantages<br>- Loop optimization (invariant computation)<br>- Peephole optimization<br>- Code generator design issues<br>- Code generation from DAG<br>- Machine-independent optimizations (data flow analysis, constant propagation, liveness analysis, CSE) | 6 |
