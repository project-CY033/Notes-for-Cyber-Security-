| Unit | Title                          | Subtopics                                                                 |
|------|--------------------------------|--------------------------------------------------------------------------|
| 1    | **Introduction**               | - Objective, scope, and outcome of the course<br>- Compiler, Translator, Interpreter definitions<br>- Phases of a compiler<br>- Bootstrapping<br>- Review of Finite automata lexical analyzer<br>- Input and recognition of tokens<br>- LEX: A lexical analyzer generator<br>- Error handling | 6 |
| 2    | **Review of CFG & Parsing**    | - Ambiguity in grammars<br>- Top-down parsing (LL grammars, recursive descent)<br>- Bottom-up parsing (Shift-reduce, LR parsers)<br>- Construction of SLR, CLR, and LALR parsing tables<br>- Parsing with ambiguous grammars<br>- Operator precedence parsing<br>- YACC: Automatic parser generator<br>- Error handling in LR parsers | 10 |
| 3    | **Syntax-Directed Translation** | - Construction of syntax trees<br>- S-Attributed and L-Attributed definitions<br>- Top-down translation<br>- Intermediate code forms (postfix, DAG, Three-address code)<br>- TAC for control structures<br>- Triples and quadruples representation<br>- Boolean expressions and control structures | 10 |
| 4    | **Runtime Environments**       | - Storage allocation strategies<br>- Heap management<br>- Activation records<br>- Accessing local/non-local names<br>- Parameter passing<br>- Symbol table organization and data structures | 8 |
| 5    | **Optimization & Code Generation** | - Basic blocks and control flow graphs<br>- DAG representation and advantages<br>- Loop optimization (invariant computation)<br>- Peephole optimization<br>- Code generator design issues<br>- Code generation from DAG<br>- Machine-independent optimizations (data flow analysis, constant propagation, liveness analysis, CSE) | 6 |
