## 🔒 **Experiment 4: Explore, Execute and Analyze Traffic using TCPDump and Netdiscover**

---

### 🎯 **Objective**

To monitor, capture, and analyze network traffic using **TCPDump** and **Netdiscover** tools for the purpose of understanding real-time packet data and discovering active devices in the network.

---

### 🛠️ **Tools Required**

* Linux system (Kali Linux/Ubuntu recommended)
* **tcpdump** (Packet capture and analysis tool)
* **netdiscover** (Active host scanning tool)

---

## 🧪 Part A: Using `TCPDump` for Traffic Analysis

### 🔍 **Purpose**

To capture and inspect network traffic at a granular level to analyze protocols, IP communication, and possible security threats.

---

### ✅ **Steps to Perform**

1. **Open Terminal in Kali/Ubuntu**
   Ensure you have root privileges (`sudo` access).

2. **Identify Active Network Interface**

   ```bash
   ip a
   ```

   Look for interface name like `eth0`, `wlan0`, etc.

3. **Capture Traffic on Interface**
   Example:

   ```bash
   sudo tcpdump -i wlan0
   ```

4. **Save Output to a File**

   ```bash
   sudo tcpdump -i wlan0 -w traffic.pcap
   ```

5. **Capture Specific Traffic (like HTTP)**

   ```bash
   sudo tcpdump -i wlan0 port 80
   ```

6. **Stop the Capture**
   Press `Ctrl + C`

7. **Analyze Captured Packets using Wireshark (Optional GUI Analysis)**

   ```bash
   wireshark traffic.pcap
   ```

---

### 📊 **Observation/Analysis**

* Analyze source and destination IPs.
* Observe TCP handshake (`SYN`, `ACK`) and HTTP GET/POST requests.
* Check for anomalies (unusual ports, IPs, packet size).

---

## 🧪 Part B: Using `Netdiscover` for Host Discovery

### 🔍 **Purpose**

To scan the local subnet to identify live hosts using ARP packets.

---

### ✅ **Steps to Perform**

1. **Open Terminal**

2. **Run Netdiscover (on default interface)**

   ```bash
   sudo netdiscover
   ```

3. **Or Scan a Specific Subnet**

   ```bash
   sudo netdiscover -r 192.168.1.0/24
   ```

4. **Output Analysis**
   You'll see a table showing:

   * IP addresses
   * MAC addresses
   * Vendor (like TP-LINK, Intel)

---

### 📊 **Observation/Analysis**

* Check how many live hosts are present.
* Match MAC address vendors to verify devices.
* Useful in identifying unauthorized devices or mapping a network.

---

## 🧠 **Conclusion**

* `tcpdump` allows deep packet-level inspection which is vital for protocol-level analysis and intrusion detection.
* `netdiscover` is quick and effective for identifying active devices in a LAN, useful for mapping and auditing.
* Both tools offer insight into network behavior, helping in detection of anomalies and threats.

---

## ✅ **Precautions**

* Run with **sudo/root** permissions.
* Ensure proper interface is selected.
* Avoid scanning public networks without permission (legal implications).
* Use filters to avoid capturing large unnecessary traffic.
