 
## 🧪 Experiment: Reporting and Analyzing Network-Related Threats Using Tools

---

### 🎯 **Objective:**

To **identify, analyze**, and **report** network-based threats (like port scanning, sniffing, suspicious traffic, etc.) using common **network security tools**.

---

## 🛠️ Tools Used:

1. **Wireshark** – Packet analyzer/sniffer
2. **Nmap** – Network scanner
3. **Snort** – Intrusion Detection System (IDS)
4. **Netstat / TCPView** – Network connection monitor
5. **Kali Linux Tools (optional)** – For offensive simulation (e.g., Metasploit, hping3)

---

## 🔍 **Threats You Can Detect:**

* Unauthorized port scanning
* Packet sniffing or MITM (Man-in-the-Middle)
* Malware communication (suspicious outbound traffic)
* SYN flood (DoS attempt)
* ARP spoofing

---

## 🧑‍🔬 **How to Perform the Experiment:**

### 🔸 **Step 1: Setup the Environment**

* Install tools like **Wireshark**, **Nmap**, **Snort** (if not already installed).
* Ensure two systems are on the same network:

  * **Attacker System** (Kali Linux or any system with scanning tools)
  * **Victim System** (Windows/Linux with Wireshark and Snort)

---

### 🔸 **Step 2: Use Nmap to Simulate a Threat (Port Scanning)**

On the **attacker machine**, run:

```bash
nmap -sS <victim-ip>      # Stealth scan
nmap -O <victim-ip>       # OS detection
```

> This simulates unauthorized reconnaissance activity.

---

### 🔸 **Step 3: Capture Traffic with Wireshark**

On the **victim system**:

1. Open Wireshark.
2. Start capturing packets on the active interface.
3. Let it run while the scan from Nmap is being executed.

✅ **What to look for in Wireshark:**

* SYN packets to multiple ports (`Flags [S]`)
* Excessive traffic from a single IP
* Protocols: TCP, ARP (in spoofing), ICMP

---

### 🔸 **Step 4: Analyze Traffic and Save Report**

1. Use Wireshark filters:

   ```bash
   ip.addr == <attacker-ip>
   tcp.flags.syn == 1 and tcp.flags.ack == 0
   ```
2. Identify patterns like:

   * Multiple port probes
   * Repeated ARP replies (in ARP spoofing)
3. Export packet captures:

   * File → Export As → `.pcap` or `.txt`
4. Write a **brief report** mentioning:

   * Time of attack
   * Type of attack (e.g., port scan)
   * Source IP
   * Target port/IP
   * Packet evidence (screenshots)

---

### 🔸 **Step 5: Use Snort for Real-Time Threat Detection**

Run Snort with a basic configuration:

```bash
snort -A console -i eth0 -c /etc/snort/snort.conf
```

Watch for alerts like:

* TCP port scan detection
* ICMP flood
* Shellcode attempts

---

## 📄 **Sample Report Format:**

```markdown
### Network Threat Analysis Report

**Date:** 04-June-2025  
**Tool Used:** Wireshark, Nmap, Snort  
**Source IP (Attacker):** 192.168.1.50  
**Target IP:** 192.168.1.10  
**Type of Threat:** Stealth Port Scanning (SYN Scan)  
**Details:**
- SYN packets detected across multiple ports.
- Scan initiated using Nmap.
- No ACK flags seen → Unacknowledged → Possible scan.
- Alert triggered by Snort IDS at 13:45 hrs.

**Conclusion:**
A stealth scan was performed. This is typically used for reconnaissance before launching an attack. Immediate action recommended: block IP, monitor for further suspicious behavior.

**Attachments:**
- Wireshark Screenshot
- Snort Console Output
```
