## 🔧 Part (a): Locating Boats and Ship Locations via Shodan

### ✅ **Steps:**

1. **Visit Shodan:**
   Go to [https://www.shodan.io](https://www.shodan.io).

2. **Login/Register:**
   Create a free account (login gives more access).

3. **Search Query:**
   Use the following filters to locate maritime devices:

   ```
   "AIS" port:4001 OR port:10110
   ```

   * AIS = Automatic Identification System (used in marine vessels)
   * Common ports: 4001 (TCP), 10110 (UDP)

4. **Analyze Results:**

   * View IP, Location, Organization, Open Ports
   * Use the **map view** for better geolocation visualization.

### ⚠️ **Note:**

This data is **publicly exposed**, but **do not** try to access or tamper with the devices.

## 🎥 Part (b): Searching and Capturing Live Cameras on Shodan

### ✅ **Steps:**

1. **Go to Shodan search bar** and enter:

   ```
   has_screenshot:true port:554 OR port:81 "webcamXP"
   ```

   * `port:554` → RTSP (real-time streaming)
   * `"webcamXP"` → Common IP webcam software
   * `has_screenshot:true` filters devices with camera screenshots

2. **Explore Webcam Results:**

   * Use filters like **country**, **organization**, **ISP**
   * Click on IPs to see camera streams (read-only)

3. **Capture/Save Info:**

   * Take screenshots (for educational purposes)
   * Record details like IP, software used, camera location

### ⚠️ **Ethical Warning:**

Never interact or exploit these devices — only observe for academic/research use.

## 📜 Part (c): Writing a Small NSE Script

### 🧠 What is NSE?

NSE (Nmap Scripting Engine) allows users to write scripts to automate networking tasks such as vulnerability detection, info gathering, etc.

### ✅ **Steps to Write NSE Script:**

1. **Install Nmap:**
   Download from [https://nmap.org/download.html](https://nmap.org/download.html)

2. **Create Script File:**

   * Filename: `simple-http-header.nse`
   * Location: `/usr/share/nmap/scripts/` (Linux) or `Nmap/scripts/` (Windows)

3. **Sample NSE Script:**

   ```lua
   local http = require "http"
   local shortport = require "shortport"

   description = [[
   Fetches and prints the HTTP headers of a web server.
   ]]

   author = "Your Name"

   license = "Same as Nmap--See https://nmap.org/book/man-legal.html"

   categories = {"discovery", "safe"}

   portrule = shortport.http

   action = function(host, port)
     local response = http.get(host, port, "/")
     if response then
       return response.rawheader
     end
     return "No response received"
   end
   ```

4. **Run NSE Script:**

   ```bash
   nmap -p 80 --script=simple-http-header.nse <target-ip>
   ```

5. **View Output:**

   * Headers like `Server`, `Date`, `Content-Type` will be displayed.
