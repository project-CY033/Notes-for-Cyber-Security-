# 3. Nmap and live scanning on ports and networks NFS,SMB,SMTP enumeration


---

### 🔬 **Experiment Title:**

**Nmap and Live Scanning on Ports and Networks – NFS, SMB, SMTP Enumeration**

---

### 🎯 **Objective:**

To use Nmap and related tools to detect open ports and enumerate services such as:

* **NFS (Network File System)**
* **SMB (Server Message Block)**
* **SMTP (Simple Mail Transfer Protocol)**

---

### 🧰 **Tools Required:**

* Kali Linux (or any Linux with Nmap installed)
* Terminal
* Network connection to target
* `nmap`, `enum4linux`, `smbclient`, `showmount`, etc.

---

### 🛠️ **Step-by-Step Procedure:**

---

#### 🔍 **1. Basic Network Discovery:**

First, identify live hosts in the network.

```bash
nmap -sn 192.168.1.0/24
```

> This pings all systems in the subnet and shows live hosts.

---

#### 🔍 **2. Port Scanning on a Target Host:**

```bash
nmap -sS -sV -T4 -p- 192.168.1.10
```

* `-sS`: SYN scan
* `-sV`: Service version detection
* `-T4`: Faster scan timing
* `-p-`: Scan all 65535 ports

---

### 🔍 **3. NFS Enumeration (Port 2049):**

Check if NFS is running:

```bash
nmap -p 2049 --script=nfs* 192.168.1.10
```

List exported NFS shares:

```bash
showmount -e 192.168.1.10
```

Mount the share if found:

```bash
mount -t nfs 192.168.1.10:/share /mnt/nfs
```

---

### 🔍 **4. SMB Enumeration (Ports 139, 445):**

Scan for SMB:

```bash
nmap -p 139,445 --script=smb-enum* 192.168.1.10
```

Use **enum4linux** for more detailed enumeration:

```bash
enum4linux -a 192.168.1.10
```

Try accessing SMB shares:

```bash
smbclient -L \\192.168.1.10
```

Try connecting:

```bash
smbclient //192.168.1.10/share
```

---

### 🔍 **5. SMTP Enumeration (Port 25):**

Scan and detect SMTP service:

```bash
nmap -p 25 --script=smtp* 192.168.1.10
```

Banner grabbing:

```bash
telnet 192.168.1.10 25
```

Try commands like:

```
EHLO test
VRFY root
```

These can help determine if user enumeration is possible.

---

### 📋 **Observation Table Example:**

| Service | Port | Tool Used       | Result Summary                  |
| ------- | ---- | --------------- | ------------------------------- |
| NFS     | 2049 | Nmap, showmount | Found 1 share, accessible       |
| SMB     | 445  | enum4linux      | Enumerated usernames, shares    |
| SMTP    | 25   | Nmap, telnet    | Banner info, VRFY returned user |

---

### ✅ **Conclusion:**

By using Nmap and enumeration tools, we can detect live systems, scan ports, and identify vulnerabilities in services like NFS, SMB, and SMTP. These insights are critical in preventing unauthorized access or exploitation.
