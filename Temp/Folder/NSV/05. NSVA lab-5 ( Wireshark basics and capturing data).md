# 05. NSVA lab-5 ( Wireshark basics and capturing data)

 
---

## 🧪 **Lab 5: Wireshark Basics and Capturing Data**

### 🎯 **Objective:**

To understand the basic functionality of **Wireshark**, a network protocol analyzer, and to learn how to capture and analyze network traffic.

---

### 🛠️ **Requirements:**

* Wireshark (installed on your system)
* Internet connection or local network
* Admin privileges (to capture packets)

---

## 🔁 **Steps to Perform the Experiment:**

### 🔹 **Step 1: Launch Wireshark**

1. Open Wireshark from the Start Menu (Windows) or use terminal (`wireshark`) in Linux.
2. Grant permissions if prompted.

---

### 🔹 **Step 2: Select a Network Interface**

1. You’ll see a list of available network interfaces (Wi-Fi, Ethernet, Loopback, etc.).
2. Choose the active interface (e.g., Wi-Fi if you are using wireless internet).
3. Double-click on it to **start capturing packets**.

---

### 🔹 **Step 3: Begin Network Activity**

1. Open a browser and visit some websites (e.g., [https://example.com](https://example.com)).
2. Run a ping or traceroute command in another terminal to generate traffic:

   ```bash
   ping google.com
   ```

---

### 🔹 **Step 4: Observe Packet Capture**

1. Wireshark will show all captured packets in real-time.
2. Each row is a packet with the following columns:

   * **No.** (Packet number)
   * **Time** (Time since capture started)
   * **Source** and **Destination** IPs
   * **Protocol** (e.g., HTTP, DNS, TCP, UDP)
   * **Length** (of the packet)
   * **Info** (summary)

---

### 🔹 **Step 5: Apply Filters**

Use display filters to narrow down the traffic:

* `http` → only HTTP packets
* `ip.addr == 8.8.8.8` → traffic to/from Google DNS
* `tcp.port == 80` → traffic using port 80
* `icmp` → for ping/echo traffic

---

### 🔹 **Step 6: Analyze a Packet**

1. Click on any packet.
2. The middle pane shows protocol details (Ethernet, IP, TCP/UDP, etc.).
3. The bottom pane shows raw data in hexadecimal and ASCII.

---

### 🔹 **Step 7: Stop and Save the Capture**

1. Click the red square button (🟥) to stop the capture.
2. Save the capture file:

   * **File > Save As** → Give a name like `lab5_capture.pcapng`

---

## 📊 **Optional Tasks:**

* Filter and analyze **DNS** requests (`dns`)
* Identify **HTTP GET/POST** requests
* Capture **login traffic** to see if credentials are visible in plaintext (only on unencrypted sites)

---

## 📘 **Learning Outcomes:**

* Understand how to capture live traffic.
* Learn how to apply filters to find specific types of network traffic.
* Analyze packet-level data to detect potential vulnerabilities or patterns.
