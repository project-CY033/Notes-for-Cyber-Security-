 
## 🔬 **Lab 10: Web Application Assessment with Nikto & Burp Suite**

### 🎯 **Objective:**

To perform a security assessment of a web application using **Nikto** and **Burp Suite**, identifying vulnerabilities such as outdated software, misconfigurations, insecure cookies, and input flaws.

---

## 🔧 **Tools Required:**

* **Nikto** – Command-line vulnerability scanner
* **Burp Suite (Community or Professional Edition)** – Web proxy for manual and automated testing
* **Kali Linux** or similar penetration testing OS
* A **test web application** (e.g., DVWA, BWAPP, or Metasploitable 2)

---

## 🧪 **Steps to Perform the Experiment**

---

### 🧰 **Part A: Web Application Assessment Using Nikto**

**Nikto** is an open-source web server scanner which performs comprehensive tests against web servers.

#### ✅ Steps:

1. **Open Terminal** in Kali Linux.

2. **Identify the target URL or IP** of the web application:

   ```
   e.g., http://192.168.1.100 or http://testphp.vulnweb.com
   ```

3. **Run Nikto scan**:

   ```bash
   nikto -h http://<target_ip_or_url>
   ```

4. **Optional parameters**:

   * To specify a port:

     ```bash
     nikto -h http://<target> -p 80
     ```
   * To save the output:

     ```bash
     nikto -h http://<target> -o result.txt
     ```

5. **Observe Results:**

   * Look for vulnerabilities such as:

     * Outdated server software
     * XSS
     * Directory indexing
     * Insecure HTTP headers
     * Admin panel exposures

---

### 🧰 **Part B: Web Application Assessment Using Burp Suite**

**Burp Suite** is a powerful platform for performing security testing of web applications.

#### ✅ Steps:

1. **Launch Burp Suite**:

   ```bash
   Applications → Web Application Analysis → Burp Suite
   ```

2. **Configure your browser to use Burp Suite as proxy**:

   * Go to browser settings → Network → Proxy
   * Set manual proxy to:

     * **HTTP Proxy:** 127.0.0.1
     * **Port:** 8080

3. **Enable Burp Proxy**:

   * Open Burp → Proxy → Intercept → Turn **Intercept On**

4. **Browse the target website**:

   * Open browser and visit: `http://<target>`

5. **Capture and analyze requests**:

   * Go to **HTTP history** tab to analyze each request and response.
   * Observe cookies, headers, parameters, etc.

6. **Use Intruder Tool (Optional)**:

   * Right-click on a request → Send to Intruder
   * Use it to test for SQLi, XSS, LFI, etc., by injecting payloads

7. **Use Repeater Tool**:

   * Send request to **Repeater** to manually modify and resend

8. **Analyze vulnerabilities**:

   * Look for weak input validation, missing CSRF tokens, vulnerable parameters

---

## 📄 **Expected Observations:**

| Tool      | Finding Examples                                            |
| --------- | ----------------------------------------------------------- |
| **Nikto** | - Outdated Apache version<br>- X-XSS-Protection not enabled |
| **Burp**  | - SQL injection in login<br>- XSS in search field           |

---

## ✅ **Conclusion:**

Using **Nikto**, we can perform quick scans to identify common server misconfigurations and vulnerabilities. **Burp Suite** allows deep manual testing, helping security professionals simulate real-world attacks like SQL Injection, XSS, and insecure sessions. Both tools are essential in a web application penetration tester's toolkit.
