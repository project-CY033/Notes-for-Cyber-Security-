## 🔬 **Lab 8: Nessus Installation and Configuration**

### 🎯 **Objective:**

To install and configure Nessus Vulnerability Scanner and perform basic scanning on a local or remote system to detect vulnerabilities.

---

## 🧰 **Requirements:**

* Host OS: **Windows/Linux**
* Guest OS: **Kali Linux (preferred)** or any Linux distro
* Internet connection
* Browser (for accessing Nessus UI)
* Administrative/root privileges

---

## 📥 **Step 1: Download and Install Nessus**

### ✅ For **Kali Linux** (Debian-based distros):

1. Go to the official Nessus download page:
   [https://www.tenable.com/downloads/nessus](https://www.tenable.com/downloads/nessus)

2. Select:

   * **Product:** Nessus
   * **Operating System:** Debian/Kali (choose `.deb` file)

3. Download via terminal or browser.
   For example, via terminal:

   ```bash
   wget https://www.tenable.com/downloads/api/v1/public/pages/nessus/downloads/<link>.deb
   ```

4. Install the package:

   ```bash
   sudo dpkg -i Nessus-<version>.deb
   ```

5. Fix dependencies if needed:

   ```bash
   sudo apt-get install -f
   ```

---

## 🔄 **Step 2: Start Nessus Service**

Start the Nessus daemon:

```bash
sudo systemctl start nessusd.service
```

To enable Nessus to run at startup:

```bash
sudo systemctl enable nessusd.service
```

---

## 🌐 **Step 3: Access Nessus Web Interface**

Open your browser and go to:

```
https://localhost:8834
```

> ⚠️ **Note:** You might see a certificate warning. Click **"Advanced" → "Accept the Risk and Continue."**

---

## 🛠️ **Step 4: Initial Setup & Configuration**

1. **Select Product:**

   * Choose **Nessus Essentials (Free)** or **Nessus Professional** if you have a license.

2. **Register an Account** (or login to Tenable)

3. **Get Activation Code:**

   * For **Nessus Essentials**, register here:
     [https://www.tenable.com/products/nessus/nessus-essentials](https://www.tenable.com/products/nessus/nessus-essentials)
   * Activation code will be sent to your email.

4. **Enter Activation Code** in the web interface

5. Nessus will now **download and install plugins** (this may take 10–20 mins depending on internet speed)

---

## 🔍 **Step 5: Perform a Vulnerability Scan**

1. Log into Nessus Web UI after setup.

2. Click on **"New Scan"**

3. Choose scan type:

   * **Basic Network Scan** for general vulnerabilities.
   * **Advanced Scan** for more configuration.

4. Fill in scan details:

   * **Name:** e.g., Localhost Scan
   * **Targets:** IP address or domain (e.g., `127.0.0.1`, `192.168.1.1`, or domain name)

5. Click **"Save"**, then **"Launch"** the scan.

---

## 📊 **Step 6: View Scan Results**

After the scan finishes:

* Click the scan name to open results.
* View:

  * Vulnerability Severity Levels (Critical, High, Medium, Low, Info)
  * Affected ports/services
  * Recommendations to fix issues
