## 🔍 **2. Scanning and Its Types**

Scanning is a process used during the information-gathering phase of ethical hacking or penetration testing. It involves examining networks, systems, and services to identify potential vulnerabilities that could be exploited.

---

### **Types of Scanning**

---

### ✅ **1. Network Scanning**

**Definition**: Network scanning is the process of discovering active hosts, IP addresses, and devices on a network.

**Purpose**:

* Identifying live hosts.
* Detecting devices (routers, switches, computers).
* Mapping network topology.

**Tools**:

* `Nmap`
* `Angry IP Scanner`
* `Advanced IP Scanner`

**Command Example**:

```bash
nmap -sn 192.168.1.0/24
```

(*Performs a ping scan to find active devices on the subnet*)

---

### ✅ **2. Port Scanning**

**Definition**: Port scanning is used to identify open ports and the services running on a target machine.

**Purpose**:

* Determine which ports are open.
* Identify services (HTTP, FTP, SSH, etc.).
* Find vulnerable services.

**Types of Port Scanning**:

* **TCP Scan (SYN Scan)**: Stealth scan to check TCP ports.
* **UDP Scan**: Checks for open UDP ports.
* **Xmas/FIN/NULL Scans**: Bypass some firewalls.

**Tools**:

* `Nmap`
* `Netcat`

**Command Example**:

```bash
nmap -sS 192.168.1.10
```

(*Performs a stealth TCP SYN scan on the target*)

---

### ✅ **3. Vulnerability Scanning**

**Definition**: Vulnerability scanning identifies security loopholes, misconfigurations, and known vulnerabilities in systems or applications.

**Purpose**:

* Detect outdated software, weak passwords, or misconfigurations.
* Analyze the risk level (high/medium/low).
* Generate security reports.

**Tools**:

* `OpenVAS`
* `Nessus`
* `Nikto`
* `Nmap` (with scripts)

**Command Example (Nmap)**:

```bash
nmap --script vuln 192.168.1.10
```

(*Runs vulnerability detection scripts on the target*)

---

## 🧪 How to Perform the Experiment (Step-by-Step)

---

### **Requirements**:

* Kali Linux (or Parrot OS)
* Internet access or a test network
* Tools: `Nmap`, `Nikto`, `OpenVAS` (or Nessus), optional: `Metasploitable` for practice

---

### **Step-by-Step Procedure**

#### 🔹 **1. Network Scanning**

```bash
nmap -sn 192.168.1.0/24
```

* This identifies active hosts on your local network.
* You will get a list of IPs that are online.

#### 🔹 **2. Port Scanning**

```bash
nmap -sS 192.168.1.10
```

* Replace `192.168.1.10` with the IP of a discovered host.
* This will show which ports are open and which services are running.

#### 🔹 **3. Vulnerability Scanning (Basic)**

```bash
nmap --script vuln 192.168.1.10
```

* Runs default vulnerability scripts against the target system.

#### 🔹 **4. Using Nikto for Web Vulnerability Scanning**

```bash
nikto -h http://192.168.1.10
```

* Checks for outdated web servers, misconfigurations, and security issues.

#### 🔹 **5. Using OpenVAS or Nessus (Optional)**

* Launch OpenVAS (`gvm` or `greenbone`).
* Create a target scan configuration.
* Run a full vulnerability assessment.

---

### ✅ **Precautions**

* Do not scan unauthorized networks.
* Use virtual labs like Metasploitable or DVWA for safe practice.
* Always inform the network owner if doing this in real environments.

---

## 📋 **Conclusion**

Scanning is a critical step in assessing the security of networks and systems. Understanding network, port, and vulnerability scanning helps identify weak points and protect systems from cyber-attacks.
