### 🔍 **Experiment 1.1: OWASP ESAPI Security**

**Objective:**
To understand how to integrate and use OWASP Enterprise Security API (ESAPI) to protect web applications from common security threats such as XSS, SQL Injection, and Input Validation vulnerabilities.

**Requirements:**

* Java (JDK 8 or above)
* Apache Tomcat or any servlet container
* Maven/Gradle
* IDE (Eclipse, IntelliJ IDEA)
* OWASP ESAPI Jar files

**Steps to Perform:**

1. **Set Up Your Java Web Application:**

   * Create a basic Java web app using Maven or any IDE.
   * Set up a simple HTML form to collect user input (e.g., name, email).

2. **Add ESAPI Dependency:**

   * Download or add ESAPI dependency via Maven:

     ```xml
     <dependency>
         <groupId>org.owasp.esapi</groupId>
         <artifactId>esapi</artifactId>
         <version>2.2.3.1</version>
     </dependency>
     ```

3. **Configure ESAPI.properties:**

   * Place `ESAPI.properties` and `validation.properties` files in the `resources` directory.
   * Customize as per your environment.

4. **Apply ESAPI Input Validation:**

   * In your servlet or controller, validate and encode input:

     ```java
     String safeInput = ESAPI.encoder().encodeForHTML(request.getParameter("username"));
     ```

5. **Test for Security:**

   * Try injecting `<script>alert(1)</script>` to test XSS prevention.
   * Use ESAPI logging for audit:

     ```java
     ESAPI.logger().info(Logger.SECURITY_SUCCESS, "User input sanitized successfully.");
     ```

### 🔐 **Experiment 1.2: Java - Spring Security, JSR 303 Validator**

**Objective:**
To use Spring Security for authentication/authorization and JSR 303 for input validation in a Java web application.

**Requirements:**

* Java (JDK 8 or above)
* Spring Boot
* Maven/Gradle
* Spring Security, Hibernate Validator (JSR 303)

**Steps to Perform:**

1. **Create a Spring Boot Project:**

   * Use Spring Initializr or manually configure it with:

     * Spring Web
     * Spring Security
     * Spring Boot DevTools
     * Validation (JSR 303)

2. **Set Up Spring Security:**

   * Add basic login configuration in `SecurityConfig.java`:

     ```java
     @Configuration
     @EnableWebSecurity
     public class SecurityConfig extends WebSecurityConfigurerAdapter {
         @Override
         protected void configure(HttpSecurity http) throws Exception {
             http
                 .authorizeRequests()
                 .anyRequest().authenticated()
                 .and()
                 .formLogin().permitAll()
                 .and()
                 .logout().permitAll();
         }
     }
     ```

3. **Use JSR 303 Annotations in a Model:**

   ```java
   public class User {
       @NotNull
       @Size(min=2, message="Name should have at least 2 characters")
       private String name;

       @Email
       private String email;
   }
   ```

4. **Bind with Controller and Validate:**

   ```java
   @PostMapping("/register")
   public String registerUser(@Valid @ModelAttribute("user") User user, BindingResult result) {
       if(result.hasErrors()) {
           return "form";
       }
       // Save user
       return "success";
   }
   ```

5. **Test Security Features:**

   * Try accessing `/dashboard` without login — it should redirect to login.
   * Enter invalid data — JSR 303 should trigger validation messages.
